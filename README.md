# Trapbound

Trapbound is a free, mobile-friendly platform game that runs in a modern web browser. It has five original trap-filled stages, touch controls, keyboard controls, sound effects, a pause menu, and a locally saved best time.

## Play

Visit the game at https://arkmediocre.github.io/Trapbound/ after the Pages workflow has deployed successfully.

- Move: **A/D** or **Left/Right Arrow**
- Jump: **Space**, **W**, or **Up Arrow**
- Retry the stage: **R**
- Pause: **Esc** or the pause button
- Phones and tablets: use the on-screen left, right, and jump buttons

GitHub Pages publishes the static game from `index.html`. Each push to `main` automatically republishes the site through `.github/workflows/pages.yml`.
